# Fotos Swipe

App Android para limpiar tu galería deslizando:

- Desliza **arriba/abajo** para navegar entre fotos.
- **Izquierda** = eliminar (va a lista de espera 5 min). **Derecha** = conservar.
- Botón **🔓 Bloquear** en cada foto: impide eliminarla desde la app.
- **Pendientes**: revisa y restaura fotos antes de que pasen los 5 minutos.

## Compilar con GitHub
1. Sube todo este contenido a un repositorio (rama `main`).
2. Ve a la pestaña **Actions** → "Compilar APK" (se ejecuta solo al subir; o usa *Run workflow*).
3. Al terminar, abre la ejecución y descarga **FotosSwipe-APK** (Artifacts). Dentro está `app-debug.apk`.
